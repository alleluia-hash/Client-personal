# HUD Mod 1.1.0 (Fabric 1.20.1, client only)

Needs Fabric Loader 0.15+ and **Fabric API 0.92.2+1.20.1**.

- Keystroke overlay: W, A, S, D, space, LMB, RMB. Keys light up while held.
- FPS and block coordinates.
- Ping (latency to the server).
- Armor durability left, per piece.
- Potion effects with timers.
- Food and saturation values.
- Press **K** to open the menu and switch each piece on or off. Settings reset when the game restarts.

This mod only draws on screen. It doesn't change gameplay, automate actions, or give any advantage. Check each server's rules before using client mods there.

Build: Java 17 and Gradle 8.5, then `gradle build`. The jar is `build/libs/hud-mod-1.1.0.jar`.
